# Bulk filing

Many linked issues from one manifest: a spec split, a review's findings, a migrated workset.

- **One Python script file** drives create, fill, link and verify. Harness auto mode and worktree sessions refuse compound shell `gh` commands (GraphQL with braces, heredocs, `&&` chains). Call `subprocess` with `stdin=subprocess.DEVNULL`, because a `gh` call in a loop otherwise eats the loop's input. Pop `GH_TOKEN` from the env. Stop at the first failure, so a later step never reports an earlier one as done.
- **Before creating:** check every manifest key has a non-empty body file. For a spec split, collect every active requirement ID in the spec, expand ranges such as `X-001 to X-011` in the issue texts, and list any ID no issue names.
- **Create every issue first,** in dependency-layer order so numbers follow build order. Manifest titles carry the `<type>: ` prefix, and each create passes its `type:<type>` label. Bodies name siblings as `{{KEY}}`. Write `map.json` after each create so a rerun resumes. Siblings named in `## Notes` can form cycles, so a blockers-first create order cannot fill them.
- **Then one fill pass** substitutes the keys and runs `gh issue edit --body-file` only on bodies that held one. Match only manifest keys, with digits allowed (`[A-Z0-9_]+`, or a key like `E2E_TAG` silently fails), since a body may quote `{{PLACEHOLDER}}` or `${{ github.… }}`. Strip braces when the deps column holds `{{KEY}}`. `owner/repo#{{KEY}}` fills to `owner/repo#N` with no second `#`. Read a file into a variable before reopening it for writing: `open(p, "w")` truncates first, and the edit then pushes an empty body. Refuse to push an empty file.
- **Then link, then verify in one call:** an aliased GraphQL query (`i2: issue(number:2){…} i3: …`) returning `blockedBy`, `assignees.totalCount` and `body`. Compare the `#N` refs under `## Depends on` with `blockedBy`, and flag leftover keys and bodies with no `## Depends on` (a blank body). Keep the jq program in a file. Flip to `factory:ready` only after it reads clean.
