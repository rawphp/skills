# pr-brief-video field lessons

Lessons from real runs that change how the next run goes. Apply while scripting and previewing.

- A `code` card heading longer than ~55 characters wraps into the first block. Use `File.php · Class::method()`, not the full path.
- `look` card paths over ~38 characters run into the symbol column. Drop the leading `Http/` or `src/`.
- A `flow` lane `sub` over ~30 characters wraps under a 2-word title. Keep it to the route.
- A `captions.replace` entry whose key equals its value in a different case (`"api": "api"`) lowercases the spoken word. Only map what changes.
- A cue word that also opens the scene ("Surveys and chat." then a row cued on "chat") fires at 0 s. `cues.py` flags repeats; pick a word that appears once.
